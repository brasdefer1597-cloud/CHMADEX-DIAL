# 🧬 Chalamandra QuantumMind v4.1

### Dialectical Quantum Engine: Chola, Malandra, Salamandra. Decodificación magistral 369.

Chalamandra es una extensión de Chrome de **Arquitectura Híbrida Élite** que combina el poder de la nube con la eficiencia de la IA local para decodificar la realidad a través de la dialéctica.

## 🚀 Características Principales

*   **Arquitectura Híbrida:** Utiliza **Gemini Cloud** (1.5 Flash/Pro) para análisis profundos y **Gemini Nano** (Chrome Built-in AI) para síntesis ultra-rápidas en el borde.
*   **Tríada Dialéctica:**
    *   **Tesis:** Generada bajo las personas *Chola*, *Malandra* o *Fresa*.
    *   **Antítesis:** Desafío crítico para romper el sesgo inicial.
    *   **Síntesis Salamandra:** Resolución magistral que integra ambos polos.
*   **Mecánica Inversa (Disrupt):** Botón de emergencia para hackear paradigmas y ofrecer visiones radicales.
*   **Context Extraction:** Captura automática de selecciones del navegador y metadatos de la página.
*   **Registros Cuánticos:** Historial persistente de decodificaciones y sistema de feedback incremental.

## 🛠 Instalación y Desarrollo

1.  **Clonar y Dependencias:**
    `npm install`
2.  **Configuración de API:**
    Crea un archivo `.env.local` y añade tu llave:
    `GEMINI_API_KEY=tu_llave_aqui`
3.  **Ejecución en Desarrollo:**
    `npm run dev`
4.  **Construcción para Extensión:**
    `npm run build`
    Luego, carga la carpeta `dist` en `chrome://extensions/` usando el "Modo de desarrollador".

## 🧩 Estructura del Proyecto

*   `/services`: Motor cognitivo (`chalamandraService.ts`).
*   `App.tsx`: Interfaz de usuario cuántica (React 19 + Tailwind).
*   `background.js`: Kernel del sistema, menús contextuales y badges.
*   `content.js`: Puente de extracción de realidad.
*   `manifest.json`: Configuración de extensión Manifest V3.

## 📘 Notas de Uso

*   Para habilitar la **IA Nano Local**, asegúrate de tener activado "Optimization Guide On Device Model" en Chrome Flags (`chrome://flags`).
*   La extensión utiliza **Google Search Grounding** para asegurar que las Tesis estén fundamentadas en datos reales de la web.
