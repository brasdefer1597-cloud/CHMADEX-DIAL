## 2024-05-14 - React Textarea Controlled Re-renders
**Learning:** In React, typing in a controlled `<textarea>` bound to state via `onChange` triggers a full component re-render on every keystroke. In a large component like `App.tsx`, this can be a significant performance bottleneck, causing typing to feel sluggish, especially as the component grows or when it contains complex elements.
**Action:** Use an uncontrolled component with a `useRef` for rapid text input where the immediate state is not strictly required for other parts of the UI during the typing process. If the state is needed, consider debouncing the state update or extracting the input into a smaller, isolated component to limit the blast radius of re-renders. We should use uncontrolled textarea here because we already have `useRef` mentioned in the memory: "App.tsx uses an uncontrolled `<textarea>` with a `useRef` to manage the main text input. This prevents full application re-renders on keystrokes, significantly improving performance."
