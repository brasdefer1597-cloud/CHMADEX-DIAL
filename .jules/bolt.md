## 2024-05-14 - Prevent Full-App Re-renders via Uncontrolled Inputs
**Learning:** In this specific React extension architecture with a complex UI component containing heavy rendering elements (like history lists and glowing wrappers), using a controlled `useState` for the main `<textarea>` causes a full-app re-render on every single keystroke. This causes noticeable input lag when the history list grows or when the extension is doing background work.
**Action:** Use an uncontrolled input with `useRef<HTMLTextAreaElement>(null)` for main text input fields. Only read the `current.value` when an action button is pressed (e.g. `handleProcess`) or explicitly update it via `ref.current.value = ...` when restoring state, preventing hundreds of unnecessary re-renders during typing.
