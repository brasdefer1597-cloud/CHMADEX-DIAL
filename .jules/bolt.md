## 2026-02-18 - Uncontrolled inputs for global wrapper components
**Learning:** In this architecture, `App.tsx` serves as both the state container and the main layout wrapper. When controlled inputs (`useState` for a `<textarea>`) are placed directly in such top-level components, every keystroke triggers a full reconciliation of the entire application tree (including `ResultDisplay` and `DialecticControls`), regardless of memoization strategies down the tree. Bypassing React's state cycle for the text input by using an uncontrolled `useRef` directly on the DOM node eliminates this specific architectural bottleneck, drastically improving typing responsiveness without requiring a massive refactor to context or external state management.
**Action:** When a top-level component in a simple React architecture must hold a text input, prefer uncontrolled `useRef` bindings to prevent global render cascades.
