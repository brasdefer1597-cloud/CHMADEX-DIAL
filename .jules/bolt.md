## 2024-05-14 - Prevent Full App Re-renders in Main Interface
**Learning:** The `App.tsx` component is the root of the application and contains a primary text input field (`<textarea>`). Using standard controlled component state (`useState`) for this input triggered a full re-render of the entire `App` component and all its descendants on every single keystroke. Given the complexity of the UI and animated elements, this is a significant and unnecessary performance bottleneck.
**Action:** Always favor uncontrolled inputs using `useRef` for the main text areas in this application's architecture to decouple user typing from React's rendering cycle. Retrieve the value directly from the ref only when processing or actions are triggered (e.g., `handleProcess`, `handleDisruption`).
